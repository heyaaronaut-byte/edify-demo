# Edify — Nomination Chain MVP

A clickable prototype of Edify's growth loop: a student gets nominated, asks a CEO a video question, gets an answer, and nominates 2 more people.

All CEOs and companies in the demo are fictional. Recording is simulated; uploading a real video file works. Nothing is saved — reload to reset.

## Put it live with GitHub Pages

1. Create a new **public** repo (e.g. `edify-mvp`).
2. Upload `index.html` and this `README.md` to the root.
3. Go to **Settings → Pages**.
4. Under "Build and deployment", set Source to **Deploy from a branch**, branch **main**, folder **/ (root)**, then Save.
5. After a minute or two, it's live at `https://<your-username>.github.io/edify-mvp/`.
